# Module 1: KCNA (Kubernetes and Cloud Native Associate)

**Duration:** 2 weeks (27 Oct - 9 Nov) | **Next:** [Module 2: CKA](../02-cka/)

## Exam facts

| | |
|---|---|
| Format | ~60 multiple-choice questions, online proctored |
| Time | 90 minutes |
| Pass mark | ~75% (45/60) |
| Resources | None |

## Domains (approximate weights)

| Domain | Weight | Practice questions |
|--------|--------|--------------------|
| Kubernetes Fundamentals | 46% | 1-28 |
| Container Orchestration | 22% | 29-41 |
| Cloud Native Architecture | 16% | 42-51 |
| Observability | 8% | 52-56 |
| Application Delivery | 8% | 57-60 |

## Plan

- **Week 1:** 45-60 min a day on one curriculum topic plus 15-20 practice questions. Finish with [Mock 1](mock-exams.md).
- **Week 2:** Fix weak domains, then take Mock 2 and the full [60-question bank](practice-questions.md). Sit the exam when you score 45+ comfortably.

## Focus list

- Pods, Deployments, ReplicaSets, Services, Ingress, Jobs, DaemonSets, StatefulSets
- Control plane vs node components, etcd and Raft
- CRI, CNI, CSI, OCI, runc, cgroups
- CNCF landscape: Prometheus, OpenTelemetry, Envoy, Helm, Argo CD, Knative, KEDA
- Observability pillars, GitOps, CI/CD, blue/green and canary

Both mocks at 80%+, then sit KCNA.
