# Module 3: CKAD (Certified Kubernetes Application Developer)

**Duration:** 5 weeks (22 Dec - 25 Jan) | **Previous:** [CKA](../02-cka/) | **Next:** [Module 4: KCSA](../04-kcsa/)

## Exam facts

| | |
|---|---|
| Format | Hands-on terminal tasks, ~15-20 tasks |
| Time | 2 hours |
| Pass mark | ~66% |
| Resources | kubernetes.io docs, Helm docs |

## Domains (approximate weights)

| Domain | Weight | Practice tasks |
|--------|--------|----------------|
| Application Environment, Configuration & Security | 25% | 34-48 |

## Plan

You already know the cluster from CKA, so this module is about speed with application YAML.

| Week | Focus |
|------|-------|
| 1 | Design and build: Pods, Jobs, CronJobs, multi-container Pods, image builds |
| 2 | Deployment: rollouts, canary, blue/green, Helm, Kustomize |
| 3 | Config and security: ConfigMaps, Secrets, securityContext, quotas, CRDs |
| 4 | Services, Ingress, NetworkPolicy, probes, debugging |
| 5 | Timed mocks, review every miss |
