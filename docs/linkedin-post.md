## Personal story version (recommended)

Written in first person, in plain words. Edit anything that doesn't sound like you.

Last year I went to KubeCon 2025. I walked around, listened to the talks, met people who build and run this stuff every day, and I kept seeing the Kubestronaut jackets and badges. I remember thinking, I want to be one of them. That was the moment I decided I would do it, and I didn't want to just wish for it. I wanted to see myself standing there next year with all five certifications.

So I made a plan: KCNA, CKA, CKAD, KCSA and CKS, in an order that made sense (CKS needs an active CKA, so that one had to wait).

Somewhere along the way, AI tools showed up everywhere. There was an assistant for every question, a summary for every topic. It was tempting to think I could just ask and move on. But I kept coming back to the same belief: with or without AI, I have to learn this myself. Nobody can sit the CKA lab for me. When the exam clock is running and the terminal is open, it's only me and the docs. So I used the tools to organise my notes and make practice material, and I did the learning the slow way, with my hands on a cluster.

It wasn't a straight line. I changed my plan many times. Some weeks went well, some didn't. A mock exam would go badly and I'd rewrite the schedule, go back to the weak areas and try again. What kept me going was reminding myself why I started, and being kind to myself on the bad days.

And now I'm here. [LAST EXAM] was the final one, and the set is complete after [TIME]. ☸️

If you are thinking about starting, my one piece of advice is this: don't wait until you feel ready. Make a plan, expect to change it, and keep showing up.

## Long version

I'm officially a Kubestronaut. ☸️

Kubestronaut means holding all five CNCF Kubernetes certifications at once:
• KCNA: Kubernetes and Cloud Native Associate
• CKA: Certified Kubernetes Administrator
• CKAD: Certified Kubernetes Application Developer
• KCSA: Kubernetes and Cloud Native Security Associate
• CKS: Certified Kubernetes Security Specialist

[LAST EXAM] was the last one, and it closed out the set after [TIME].

The hardest part was the planning. CKS needs an active CKA, and all five must be valid at the same time. So I planned the order around that:

1️⃣ KCNA: warm up and build the vocabulary
2️⃣ CKA: cluster admin, troubleshooting, networking, storage
3️⃣ CKAD: speed with application YAML
4️⃣ KCSA: security concepts, fresh before CKS
5️⃣ CKS: hardening, supply chain, runtime security

What worked for me:
• KodeKloud courses and labs for the core learning
• 60 practice items per exam, then two mocks each: a diagnostic one week out and a timed dress rehearsal a few days before
• One line written for every miss: what I did, what was right, which doc page to bookmark
• [TIP]

I put all of it in a repo, laid out as a short course with one module per certification:
https://github.com/skommepa/Skommepalli_Kubestronaut

Inside: the study plan, 300 practice questions and tasks, 10 mock exams, a study method and a tracker. It's unofficial practice material, not exam dumps, so please check the CNCF curriculum for current exam details.

If it helps you, fork it. If you find a mistake, open an issue or a PR.

Thank you to everyone who answered my questions and cheered me on along the way. 🙏
